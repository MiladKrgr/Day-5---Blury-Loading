## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->

- استفاده از الگوریتم نگاشت عددی (Linear Mapping) برای همگام‌سازی ترنزیشن‌ها
- ساختار سبک و بدون وابستگی به کتابخانه‌های خارجی

## Project Description 📌
<!-- Standard : Project Description  -->
This project demonstrates a dynamic blurry loading screen effect. As the numerical loading counter counts up from 0% to 100%, the blurred background image smoothly gains focus and clarity, while the percentage text gradually fades away.



---
---
---

## Features 🌏
<!-- Standard : features  -->
- Smooth loading animation powered by vanilla JavaScript
- Progressive unblur effect using CSS filter: blur
- Simultaneous opacity fade-out on the percentage counter
- Custom mathematical mapping function to sync progress and visual ranges
- Clean, minimal, and dependency-free codebase
